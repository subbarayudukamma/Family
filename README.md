## Math Strong - Math Practice App

### Overview
Math Strong is a web-based math practice application designed to help learners improve their arithmetic skills. It tracks progress per user on the device and provides engaging practice sessions for addition, subtraction, multiplication, and division.

### Features

#### Practice Modes
- **Addition** - Select from multiple difficulty ranges (0-10, 10-100, 100+)
- **Subtraction** - Select from multiple difficulty ranges (0-10, 10-100, 100+)
- **Multiplication** - Select from multiple multiplication tables (0-12)
- **Division** - Select from multiple division tables (0-12)
- **Mix Everything** - Randomly combines all operations and difficulty levels

#### Multi-Selection
✨ **NEW** - You can now select **multiple tables or ranges** for practice instead of just one:
- For **Multiplication/Division**: Select any combination of tables 0-12
- For **Addition/Subtraction**: Select any combination of difficulty ranges
- Questions are randomly generated from your selected options
- The "Mix All Tables/Ranges" button automatically selects all options

#### User Management
- Saves user names to device storage
- Tracks practice history per user
- Supports multiple users on the same device

#### Practice Features
- Large, easy-to-read question display
- Virtual keypad with keyboard support
- Toggle for negative numbers (optional)
- Real-time feedback with encouraging messages
- Running statistics display (optional)
- 30% retry rate for previously incorrect answers

#### Performance Tracking
- Session statistics:
  - Total problems solved
  - Correct/wrong answers
  - Accuracy percentage
  - Time spent (excluding feedback time)
  - Average time per problem
- Daily aggregates per user
- Recent session history
- Device-wide usage statistics across all users
- All data stored locally in browser

### How to Use

1. **Enter your name** - The app will prompt you to enter your name on first use (or use the "Change Name" button)
2. **Select a practice mode** - Choose Addition, Subtraction, Multiplication, Division, or Mix Everything
3. **Select tables or ranges** - Select one or multiple options:
   - For **Multiplication/Division**: Click tables to select them (they turn blue)
   - For **Addition/Subtraction**: Click ranges to select them (they turn blue)
   - Use the "Mix All Tables/Ranges" button to select all options at once
4. **Start Practice** - Click "Start Practice" to begin
5. **Answer questions** - Use the keypad or keyboard to enter your answers
   - Press Enter or click "Enter" to submit
   - Press Escape or click "Exit" to stop practicing
6. **View results** - See your session statistics and retry or go home

### Controls
- **Keypad buttons**: Click numbers 0-9, +/-, or backspace
- **Keyboard**: Type numbers, press Enter to submit, Escape to exit, Backspace to delete
- **+/- button**: Toggle negative sign on your answer

### Options
- **Include negative numbers**: Toggle to practice with negative operands
- **Show running stats**: Display elapsed time and current score during practice
